# Kubeflow Pipelines Exporter

## Mission

Build a production-grade Prometheus exporter for Kubeflow Pipelines.

The exporter should expose operational metrics that are currently unavailable or difficult to collect.

This project is intended to become an upstream-quality open source contribution.

---

# How You Should Work

Act as a senior software engineer.

Do not immediately write code.

Always follow this workflow.

1. Understand the problem.
2. Explore the repository.
3. Explain what you found.
4. Propose possible solutions.
5. Compare tradeoffs.
6. Recommend one approach.
7. Wait for approval if architecture changes.
8. Implement.
9. Run tests.
10. Explain what changed.
11. Suggest the next task.

---

# Communication Style

Always explain your reasoning.

Assume the repository owner is learning.

When introducing a new concept:

- explain WHY
- explain HOW
- explain alternatives
- explain tradeoffs

Never skip explanations.

---

# Coding Principles

Prefer Go standard library.

Keep packages small.

Keep functions short.

Never ignore errors.

Avoid unnecessary abstractions.

Write readable code over clever code.

---

# Before Every Commit

Verify:

- builds successfully
- tests pass
- documentation updated
- comments updated

---

# Never Do Without Approval

Changing architecture

Deleting files

Large refactoring

Adding dependencies

Changing exported interfaces

Changing metric names
